# ssu-opensource

숭실대 오픈소스기초설계 수업의 개인 프로젝트 저장소입니다.

## 프로젝트 주제

**강의자료 연동 실시간 음성 인식 기반 강의 보조 프로그램**

교수자가 배포한 강의자료(PDF·PPT)를 기준 자료로 삼아 녹음 중인 발화를 페이지 단위로 매칭하고, 녹음을 실시간으로 텍스트화해 강의 중간에 생긴 질문에도 즉시 답변하는 프로그램을 목표로 합니다.

## 폴더 구조

- `doc/` — 프로젝트 제안서
- `src/` — 소스 코드
